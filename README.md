# 🎯 CBT Portal — JEE Mains CBT Presenter & Exam Controller Platform

A complete, enterprise-grade presentation and control platform for Computer Based Tests (CBT). Designed specifically to host and present any Gemini-generated HTML tests (major papers, minor tests, topic tests) with authentic NTA styling, **real-time device telemetry**, **single active session enforcement**, and **administrator-only result confidentiality**.

---

## ⚡ Key Capabilities

### 1. 📂 Universal CBT HTML Presenter & Parser
- **Upload Any Gemini Test File**: Admin can upload any `.html` test generated by Gemini or standard JEE mock exam format.
- **Flexible Parser**: Automatically reads question count, subject divisions (Physics, Chemistry, Maths, etc.), and duration.
- **No Format Breakage**: Fully supports minor tests with 25 questions or full 75-question official papers with inline base64 images.
- **Seamless Test Bridge**: Injects an invisible security bridge into the test page without altering the original NTA look and feel.

### 2. 🛡️ Single Active Session Enforcement
- **Anti-Cheating Device Lock**: Only **one** device or browser session can be active per candidate at any given time.
- **Immediate Termination**: If a student logs in on a second phone or laptop, their previous active session is immediately terminated on the server.
- **Active Heartbeat Check**: Test screen freezes and displays a security overlay if an unauthorized duplicate login is detected.

### 3. 📱 Live Device Telemetry & Audit
- Captured on every candidate login and stored for administrative auditing:
  - **Operating System** (Windows 11, macOS, Android, iOS, Linux)
  - **Browser & Version** (Chrome, Safari, Firefox, Edge)
  - **Client IP Address** (Public IP tracking)
  - **Screen Resolution** (e.g. 1920x1080, 390x844)
  - **Login & Activity Timestamps** with real-time ping indicator (Active, Idle, Terminated).

### 4. 🔒 Role-Based Privacy & Result Control
- **Student Self-Registration**: Candidates can register with their real Gmail / email address and password.
- **Admin-Controlled Results**: 
  - **Admin Only (Default)**: Candidates only receive confirmation that their exam was submitted. Detailed scores, answer keys, and rankings are confidential and visible solely on the Admin Dashboard.
  - **Student View (Configurable)**: Admin can toggle any test to allow students to view their full NTA question review and percentile breakdown after submission.
- **Export to CSV**: Download complete exam results for Excel/Google Sheets in 1 click.

## 🚀 Quick Start (Local Setup)

### 1. Clone the repository
```bash
git clone https://github.com/darshan77762526/Test-maker.git
cd Test-maker
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the platform
```bash
npm start
```

Open your browser at `http://localhost:4000`.

---

## 🔑 Administrator Setup

Set your administrator credentials securely in your `.env` file or hosting environment variables:

```env
ADMIN_EMAIL=your_admin_email@example.com
ADMIN_PASSWORD=your_secure_password
```

When the server starts, it will automatically register this administrator account if it does not already exist.

## 🌐 Deploy to Railway / Render (1-Click)

### Option A: Railway
1. Go to [Railway.app](https://railway.app).
2. Click **New Project** → **Deploy from GitHub repo**.
3. Select `darshan77762526/Test-maker`.
4. Railway will automatically detect the `railway.json` and start the service.
5. In **Settings** → **Networking**, click **Generate Domain**.

### Option B: Render
1. Go to [Render.com](https://render.com).
2. Click **New** → **Web Service**.
3. Connect your GitHub repository.
4. Set:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Click **Create Web Service**.

### Option C: Docker
```bash
docker build -t cbt-portal .
docker run -p 4000:4000 cbt-portal
```

## 📝 How to Publish Tests as Admin

1. Sign in with your configured administrator email and password.
2. Go to the **Upload CBT HTML Paper** tab.
3. Drag & drop your Gemini `.html` file.
4. Choose whether results are **Admin Only** (default) or **Visible to Students**.
5. Click **Publish CBT Paper**.
6. The test is instantly accessible to all registered candidates!
